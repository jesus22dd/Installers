Descargar instalador BAT

La descarga se solicita al abrir esta página. Si no aparece, pulsa el botón.

  1. Busca Instalar-DotNet.bat en tus descargas.
  2. Clic derecho → Ejecutar como administrador.
  3. Acepta el permiso de Windows y espera el resultado.

El navegador puede descargar el archivo, pero no ejecutarlo ni instalar .NET automáticamente. El BAT necesita conexión a Internet y WinGet para instalar componentes.
